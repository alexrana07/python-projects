# 🎲 Random Number Generator

A simple beginner-friendly Python project that asks the user to enter a positive number and then generates a random number between `0` and the entered number.

This project was created to practice basic Python programming concepts and improve logical thinking.

## 📌 Features

* Takes input from the user
* Checks whether the input is a valid number
* Rejects numbers less than or equal to `0`
* Generates a random number
* Keeps track of the score for each valid input
* Runs continuously using a `while` loop

## 🛠️ Concepts Used

* `while` loop
* `if`, `else` conditions
* `continue`
* User input with `input()`
* Type conversion using `int()`
* String methods
* Variables
* Incrementing values
* Python `random` module
* `random.randrange()`

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command in the terminal:

```bash
python random_number.py
```

## 🎮 How It Works

1. The program asks you to enter a number.
2. It checks whether the input is a valid number.
3. The number must be greater than `0`.
4. The program generates a random number between `0` and your entered number.
5. The score increases by `1` after each valid input.
6. The program continues asking for numbers.

### Example

```text
guess the number: 10
7

1
```

Here, `10` was entered and the program generated the random number `7`.
